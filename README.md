# ⚡ Eliott+2 — موجات إليوت + استراتيجيتا سكالبينغ متوازيتان (سبوت باينانس)

مشروع تداول سبوت يعمل ب**ثلاث استراتيجيات بالتوازي** في نفس العملية وعلى نفس رأس المال:

| # | الاستراتيجية | النوع | الفريم | الفكرة |
|---|---|---|---|---|
| 1 | **Elliott_Fibonacci** | موجات إليوت الدافعة + فيبوناتشي | كشف 15m / تنفيذ 15m | أمر معلق عند تراجع 0.382 للموجة 3، وقف بنيوي، سلّم أهداف |
| 2 | **SCALP_FLOW «انجلال التدفق»** | سكالب زخم order-flow | 5m | اندلاع دلتا المشترين (CVD) مؤكدًا بـ SuperTrend/ADX، والجدران البيعية أهداف |
| 3 | **SCALP_PROFILE «ارتداد القيمة»** | سكالب ارتدادي | 5m | رمشة سيولة تحت VAL مع امتصاص CVD، والعودة نحو POC |

> الاستراتيجيات المتوازية `strategies/` الجديدة كليًا (EL2.0.0). **الوضع ورقي افتراضيًا** —
> التداول الحقيقي زر اختياري في اللوحة يتطلب مفاتيح باينانس.

## 🧠 الاستراتيجيتان المتوازيتان — كيف يقرران

### S1 — انجلال التدفق (SCALP_FLOW)
الدلتا تقود السعر: حين يتقدم CVD لأعلى مستوى في 36 شمعة بينما السعر لم يندلع بعد، فالشراء
العدواني حقيقي. **ست بوابات إلزامية**: بيانات كاملة وسعر حي قريب (لا ملاحقة) ← SuperTrend(10,2.5)
صاعد على 5m مع تأكيد 15m أو ADX ≥ 22 ← اندلاع CVD فوق EMA12 له ← حجم ≥ 1.3× المتوسط ←
موقع سليم فوق VWAP وفوق POC وبلا امتداد زائد ← هندسة R:R صافية ≥ 0.3.

- **الوقف**: ATR مضبوط بآخر قاع مؤكد، مثبت داخل 0.55–1.4×ATR
- **الأهداف**: TP1 = 1.1×ATR (جزئي 50% + BE) · TP2 = **أقرب جدار بيع من دفتر الأوامر**
  (فكرة Liquidity Radar) أو 2.2×ATR
- **الخروج المبكر**: انقلاب الدلتا مع كسر SuperTrend

### S2 — ارتداد القيمة (SCALP_PROFILE)
امتدادات خارج منطقة القيمة تجذب رمشات سيولة تُبتلع حين لا يوجد بائع حقيقي خلفها.
Volume Profile من آخر 72 شمعة 5m (POC/VAH/VAL بمنطقة قيمة 70%) ← درع ضد الترند القوي
(رفض SuperTrend هابط مع ADX ≥ 28) ← رمشة تحت VAL بإغلاق داخل القيمة ← **امتصاص**:
قاع سعري جديد بلا قاع دلتا جديد ← تقارب اختياري مع فيبو المحرك (0.618/0.786) يرفع الدرجة.

- **الوقف**: تحت الرمشة بـ 0.3×ATR · **الأهداف**: TP1 = POC · TP2 = VAH
- **الخروج المبكر**: انهيار البنية (إغلاق تحت VAL بهامش واسع)

### الإدارة المشتركة (نفس عقائد الحماية المحمية للمحرك)
فتح فوري بسعر حي (ملء صادق) · وقف-أولًا intrabar كل 20 ثانية · جزئي 50% عند TP1 + نقل
الوقف لنقطة الدخول · مهلة صفقة 90 دقيقة · تبريد رمز 45 دقيقة · سقف صفقات مفتوحة 2 ·
قاطع خسارة يومي 0.6% لكل استراتيجية · حجم بمخاطرة 0.75% مقيد بسقف قيمة صارم (لا رافعة
ضمنية) · **سبوت فقط LONG** (حارس صريح لا بيع مكشوف) · احترام زر التداول وقاطع مخاطر
المحرك · حظر ازدواج الرمز عبر الاستراتيجيات الثلاث.

**عزل صارم لدورتي الحياة**: استعلامات مراقبة محرك الموجات ترى صفوفه وحده، ودورة حياة
السكالب يملكها مديرها حصرًا — سلطان مزدوج على صف واحد = كوارث محاسبية، فمنع استباقيًا.

## 🌊 استراتيجية موجات إليوت (القلب الأصلي)

### 1) كشف الموجات (engine/pattern_detector.py — منقول حرفيًا من المشروع الأصلي MIT)
- زيجزاج بنسبة انعكاس (آلة حالة ثلاثية الأطوار) على أسعار **الإغلاق**
- محاور بأسعار High/Low الحقيقية، تناوب صارم، فصل زمني ≥ شمعتين
- نافذة منزلقة من 6 محاور P0–P5 لكل دافع مرشح

### 2) القواعد الصارمة الثلاث (engine/wave_validator.py)
| القاعدة | الشرط |
|---|---|
| W2 لا تكسر أصل W1 | P2 يبقى فوق P0 (صاعدة) |
| W3 ليست الأقصر | \|P3−P2\| > min(\|P1−P0\|, \|P5−P4\|) **و** تكسر قمة W1 |
| W4 لا تتداخل مع W1 | P4 يبقى فوق P1 (صاعدة) |

### 3) التداول
| العنصر | القيمة |
|---|---|
| الدخول | **أمر معلّق** عند حد 0.382 لتراجع الموجة 3 |
| الوقف | **بنيوي** خلف أصل الموجة 1: P0 − 0.1% |
| الأهداف | سلّم متدرج W5=W1 / 0.618×W3 / 1.618×W1 بجني جزئي 40% عند كل مرحلة |
| الحماية | BE عند 1R · R:R صافي ≥ 0.3 · أهداف مقصوصة على قمة الأسبوع |

## 🔌 التكامل البنيوي

- **جسر حقن كامل**: حزمة `strategies/` لا تستورد `vnz.py` إطلاقًا — كل الاعتماديات تُحقن
  عبر `scalp_host()` عند الإقلاع (تلافي إعادة تنفيذ الوحدة عند التشغيل `__main__`)
- **CVD من الحقيقة**: دلتا الشمعة من حقل «حجم المشتري بالتاكير» في شموع باينانس الخام
  (12 حقلًا عبر `publicGetKlines` خلف حارس الوزن) — وعند فشل بايننس انسحاب **صادق** إلى
  وضع proxy (تقريب موضعي معلن في meta ولا ينتحل الحقيقة)
- **جدران السيولة**: لقطة دفتر أوامر بوزن 1 لكل رمز في دورة المسح، تجميع صناديق 0.25×ATR
  وجدار = صندوق ≥ 6× الوسيط
- **تقارب فيبو المحرك**: زيجزاج المحرك ذاته (`zigzag_pivots` بعتبة الانعكاس نفسها) يستخرج
  آخر ساق صاعدة ومستويات 0.618/0.786 — اتساق كامل مع استراتيجية الموجات
- **اللوحة**: قسم «الاستراتيجيات المتوازية» ببطاقات حية لكل استراتيجية (مفتوح/إشارات/
  جزئي/إغلاقات/ربح اليوم/التبريد/مصدر CVD) + شارة ⚡ تدفق / ◈ قيمة على كل صف
- **نقاط API**: `/api/scalp` (محمية) + كتلة `scalp` في `/health` و`/api/all`
- **تلغرام**: أنواع `SCALP_OPEN/SCALP_PARTIAL/SCALP_CLOSE` عبر بوابة الضجيج نفسها

## ⚙️ أهم إعدادات السكالب (بيئة)

| المتغير | الافتراضي | الشرح |
|---|---|---|
| `SCALP_ENABLED` | `1` | تشغيل الطبقة المتوازية كلها |
| `SCALP_S1_ENABLED` / `SCALP_S2_ENABLED` | `1` | تفعيل كل استراتيجية على حدة |
| `SCALP_EXEC_TF` | `5m` | فريم تنفيذ السكالب |
| `SCALP_SYMBOLS` | فارغ | قائمة صريحة — وإلا أول `SCALP_SYMBOLS_N` من قائمة المراقبة |
| `SCALP_RISK_PCT` | `0.75` | مخاطرة الصفقة % من الرصيد |
| `SCALP_MAX_NOTIONAL_USDT` / `_PCT` | `1200` / `30` | سقف قيمة الصفقة (درس ضد الرافعة الضمنية) |
| `SCALP_MAX_TOTAL_OPEN` | `2` | أقصى صفقات سكالب مفتوحة معًا — البقية للموجات |
| `SCALP_COOLDOWN_SEC` | `2700` | تبريد الرمز بعد إغلاق سكالب |
| `SCALP_DAILY_LOSS_PCT` | `0.6` | قاطع خسارة يومي لكل استراتيجية |
| `SCALP_MAX_HOLD_MIN` | `90` | مهلة الصفقة |
| `SCALP_PARTIAL_PCT` | `50` | نسبة الجني عند TP1 (+BE تلقائي) |

القائمة الكاملة في `ENV_VARIABLES.txt` — وإعدادات موجات إليوت كما هي في fibo-elio.

## 🚀 التشغيل

```bash
pip install -r requirements.txt
python vnz.py            # اللوحة على http://localhost:10000
```

## ☁️ النشر على Render
1. أنشئ Web Service من هذا المستودع — `render.yaml` جاهز بالاسم `eliott-plus-2`
2. Build: `pip install -r requirements.txt` — Start: `python vnz.py` — Health: `/health`
3. أضف `DASHBOARD_USERNAME`/`DASHBOARD_PASSWORD` واختياريًا `DATABASE_URL` (Postgres) و`TELEGRAM_BOT_TOKEN`/`CHAT_ID`
4. افتراضيًا ورقي — التداول الحقيقي من زر اللوحة بعد إضافة مفاتيح باينانس
